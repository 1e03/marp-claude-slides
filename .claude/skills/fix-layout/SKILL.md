# レイアウト修正スキル

## 概要
`$ARGUMENTS` で指定されたスライドファイルの制約違反を検出し、自動修正する。

## 実行手順

### 1. 対象ファイルの特定
- `$ARGUMENTS` でファイルパスが指定されていればそれを使用
- 未指定の場合、`output/` 内の最新の `.md` ファイルを対象とする

### 2. ルール・パターンの読み込み
- `docs/slide-rules.md` — 制約ルール
- `docs/layout-patterns.md` — レイアウトパターン集（修正時の代替案として使用）

### 3. 違反の検出
各スライドについて以下を検証:
- タイトル文字数（30文字上限）
- タイトルのコロン使用
- 1行の文字数（40文字上限）
- スライド総文字数（400文字上限）
- スライド総行数（12行上限）
- 箇条書き項目数（5項目上限）
- 箇条書きネスト（2段上限）
- 画像枚数（2枚上限）

### 4. 自動修正ルール

#### タイトルが長すぎる場合
- 不要な修飾語を削除
- 体言止めに変更
- サブタイトルに分離

#### タイトルにコロンがある場合
- コロンを削除し、サブタイトルとして分離
- または「〜」「−」などで代替

#### 1行が長すぎる場合
- 適切な位置で改行
- 冗長な表現を簡潔にする

#### スライドの文字数・行数が超過している場合
- 情報を2枚のスライドに分割
- `docs/layout-patterns.md` から適切なレイアウトを選択
- 例: テキスト過多 → `two-col` で2列化、項目過多 → 2スライドに分割

#### 箇条書きが多すぎる場合
- 関連項目をグルーピングして削減
- サブ項目を別スライドに分離
- `metric-card` や `three-col` パターンへの変換を検討

#### 箇条書きのネストが深すぎる場合
- フラットな構造に変換
- 見出し + 箇条書きの組み合わせに変更

### 5. 修正の適用
- Edit ツールを使って元ファイルを直接修正する
- 各修正ごとにどのルールに対応する修正かを明示する

### 6. 結果レポート
```
## 修正レポート: {ファイル名}

### 修正サマリー
- 検出された違反: X件
- 修正済み: X件
- 手動確認が必要: X件

### 修正内容
1. スライドX: {修正内容の説明}
2. ...
```
