# 品質検証スキル

## 概要
`$ARGUMENTS` で指定されたスライドファイル（未指定の場合は `output/` 内の最新ファイル）の品質を検証し、制約ルールへの準拠率を数値化する。

## 実行手順

### 1. 対象ファイルの特定
- `$ARGUMENTS` でファイルパスが指定されていればそれを使用
- 未指定の場合、`output/` 内の最新の `.md` ファイルを対象とする

### 2. 設定とルールの読み込み
- `config.yml` の `text_rules` セクションを読み込み、検証の閾値を取得する
- `docs/slide-rules.md` を読み込み、検証基準の詳細を確認する

### 3. スライドの解析
- マークダウンを `---` で分割し、個別スライドに分解する
- フロントマター部分は検証対象から除外する
- 各スライドについて以下の情報を抽出:
  - タイトル（`#` で始まる行）
  - 本文テキスト
  - 箇条書き項目数
  - 行数
  - 文字数（マークダウン記法・HTMLタグを除く）
  - 画像数（`![` の出現回数）
  - 使用クラス（`<!-- _class: xxx -->`）

### 4. 各スライドの検証
以下のルールに対して検証を実行（閾値は `config.yml` の `text_rules` から取得）:

| ルール | config.yml のキー |
|--------|------------------|
| タイトル文字数 | `title.max_chars` |
| タイトル禁止文字 | `title.forbidden_chars` |
| 1行の文字数 | `body.max_chars_per_line` |
| スライド総文字数 | `body.max_chars_per_slide` |
| スライド総行数 | `body.max_lines_per_slide` |
| 箇条書き項目数 | `bullet.max_items` |
| 箇条書きネスト | `bullet.max_nesting` |
| 画像枚数 | `image.max_per_slide` |
| 絵文字数 | `emoji.max_per_slide` |

### 5. レポート出力
以下の形式でレポートを表示:

```
## 検証レポート: {ファイル名}

### サマリー
- スライド数: X枚
- 準拠率: XX.X% (XX/YY ルール準拠)
- 違反数: X件

### スライド別結果
#### スライド 1: {タイトル}
- ✅ タイトル文字数: XX文字 (上限 {title.max_chars})
- ❌ 本文行数: XX行 (上限 {body.max_lines_per_slide}) → 要修正
...

### 違反サマリー
1. スライドX: {違反内容} → {改善提案}
2. ...
```

### 6. 改善提案
違反が検出された場合、具体的な改善案を提示する:
- 長すぎるタイトル → 短縮案を提示
- 行数超過 → 分割案または適切なレイアウトパターンを提案
- 文字数超過 → 要約案を提示
