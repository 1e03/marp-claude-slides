# スライド制約ルール

スライドの品質を一定水準以上に保つための制約ルール集。
すべてのスライド作成時にこのルールを適用し、バリデーションチェックリストで確認する。

> **設定値について**: 各ルールの具体的な数値（文字数上限、項目数上限など）は
> `config.yml` の `text_rules` セクションで一元管理されています。
> 値を変更する場合は `config.yml` を編集してください。
> このドキュメントに記載された数値はデフォルト値です。

---

## 1. タイトルの制約

| ルール | 制約値 |
|--------|--------|
| 最大文字数 | 30文字以内 |
| コロン（:） | 使用禁止 |
| エクスクラメーションマーク（!） | 使用禁止 |
| 句読点 | 末尾の句点は不要 |

### 詳細

- タイトルは簡潔かつ具体的に書く
- 体言止めまたは動詞終わりを基本とする
- 疑問形は許容するが、多用しない
- 英数字はすべて半角で統一する

### バリデーションチェックリスト

- [ ] 30文字以内である
- [ ] コロンを含まない
- [ ] エクスクラメーションマークを含まない
- [ ] 末尾に句点がない
- [ ] 内容が具体的で曖昧でない

---

## 2. テキスト量の制約

| ルール | 制約値 |
|--------|--------|
| 1行あたりの最大文字数 | 40文字 |
| 1スライドあたりの最大文字数 | 400文字 |
| 1スライドあたりの最大行数 | 12行 |

### 詳細

- 1行が40文字を超える場合は改行するか、文を短くする
- 400文字を超える場合はスライドを分割する
- 12行を超える場合は情報を整理し、不要な行を削除する
- タイトル行はカウントに含める
- 空行はカウントに含めない

### バリデーションチェックリスト

- [ ] すべての行が40文字以内である
- [ ] スライド全体が400文字以内である
- [ ] コンテンツ行が12行以内である
- [ ] 情報が1スライド1メッセージに収まっている

---

## 3. 画像の制約

| ルール | 制約値 |
|--------|--------|
| 1スライドあたりの最大画像数 | 2枚 |
| 推奨解像度 | 幅1200px以上 |
| 最大ファイルサイズ | 2MB/枚 |

### 詳細

- 背景画像を使用する場合、その1枚もカウントに含む
- 画像のアスペクト比は変更しない
- 背景画像にテキストを重ねる場合は暗めのオーバーレイを適用する
- alt属性（代替テキスト）を必ず設定する

### バリデーションチェックリスト

- [ ] 画像が2枚以内である
- [ ] 各画像にalt属性が設定されている
- [ ] 画像が変形していない
- [ ] 背景画像使用時にテキストの可読性が確保されている

---

## 4. カラーの制約

| ルール | 制約値 |
|--------|--------|
| 1スライドあたりのアクセントカラー | 最大2色 |
| 使用可能なアクセントカラー | ネイビー `#1B4565`、ティール `#3E9BA4` |
| セマンティックカラー | 用途に応じて使用可（装飾目的は禁止） |

### 詳細

- グレースケール（`#333`〜`#F5F5F5`）はアクセントカラーのカウントに含めない
- 白 `#FFFFFF` と黒 `#000000` もカウントに含めない
- セマンティックカラーは意味のある場面（成功、警告、エラー、情報）でのみ使用する
- グラデーションは使用禁止

### バリデーションチェックリスト

- [ ] アクセントカラーが2色以内である
- [ ] 許可されたカラーパレットの色のみ使用している
- [ ] セマンティックカラーが適切な用途で使用されている
- [ ] グラデーションを使用していない

---

## 5. 箇条書きの制約

| ルール | 制約値 |
|--------|--------|
| 最大項目数 | 5項目 |
| 最大ネスト階層 | 2階層 |
| 1項目あたりの最大文字数 | 40文字 |

### 詳細

- 箇条書きが5項目を超える場合はグルーピングするか、スライドを分割する
- ネスト（入れ子）は2階層まで。3階層以上は禁止
- 箇条書きの各項目は簡潔にし、文章ではなくキーワードやフレーズで表現する
- 箇条書き記号のスタイルはスライド内で統一する

### バリデーションチェックリスト

- [ ] 箇条書き項目が5つ以内である
- [ ] ネストが2階層以内である
- [ ] 各項目が40文字以内である
- [ ] 記号スタイルが統一されている

---

## 6. フォントサイズの制約

| ルール | 制約値 |
|--------|--------|
| 最小フォントサイズ | 18px |
| 例外: キャプション | 14px（図表キャプションのみ） |

### 詳細

- 18px未満のテキストは最後列の聴衆に読めない
- キャプション（14px）は図表の直下に限定して使用する
- フォントサイズの種類は1スライドにつき最大3種類までを推奨する
- タイトルのサイズは本文の1.5倍以上を目安にする

### バリデーションチェックリスト

- [ ] すべてのテキストが18px以上である（キャプション除く）
- [ ] キャプションが14px以上である
- [ ] フォントサイズの種類が3種類以内である
- [ ] タイトルと本文のサイズに十分な差がある

---

## 7. テーブル（表）の制約

| ルール | 制約値 |
|--------|--------|
| 最大列数 | 5列 |
| 最大行数 | 7行（ヘッダー含む） |
| セル内の最大文字数 | 20文字 |

### 詳細

- 5列を超える場合はテーブルを分割するか、レイアウトを変更する
- 7行を超える場合は重要なデータに絞るか、スライドを分割する
- セル内のテキストは簡潔にする
- ヘッダー行は必ず設定する
- 縦線は非表示を推奨する（Marpのデフォルトスタイルを使用）

### バリデーションチェックリスト

- [ ] 列数が5列以内である
- [ ] 行数が7行以内である（ヘッダー含む）
- [ ] 各セルが20文字以内である
- [ ] ヘッダー行が設定されている

---

## 8. 禁止事項

### 絵文字の使用制限

- 装飾目的の絵文字は使用禁止
- 意味を補強する目的で使用する場合、1スライドにつき最大2個まで
- タイトルでの絵文字使用は禁止

### 記号の使用制限

- タイトルのコロン（:）は禁止（副題がある場合はサブタイトル要素を使う）
- タイトルのエクスクラメーションマーク（!）は禁止
- 連続するエクスクラメーションマーク（!!）は本文でも禁止
- 三点リーダーは「...」ではなく「…」（U+2026）を使用する

### その他の禁止事項

- 全角英数字の使用（半角に統一する）
- 不必要な装飾（アンダーライン、取り消し線の乱用）
- テキストの中央揃えと左揃えの混在（1スライド内で統一する）
- 異なるフォントファミリーの混在

### バリデーションチェックリスト

- [ ] 装飾目的の絵文字を使用していない
- [ ] タイトルに禁止記号を含まない
- [ ] 全角英数字を使用していない
- [ ] テキスト揃えが統一されている
- [ ] フォントファミリーが統一されている

---

## 総合バリデーションチェックリスト

スライド作成後、以下をすべて確認する。

### 構成

- [ ] 1スライド1メッセージになっている
- [ ] タイトルが30文字以内で具体的である
- [ ] テキスト量が制約内に収まっている（400文字、12行）

### ビジュアル

- [ ] アクセントカラーが2色以内である
- [ ] フォントサイズが18px以上である（キャプション除く）
- [ ] 画像が2枚以内である
- [ ] 十分な余白が確保されている

### テキスト

- [ ] 1行あたり40文字以内である
- [ ] 箇条書きが5項目以内、2階層以内である
- [ ] テーブルが5列7行以内である
- [ ] 禁止記号や禁止表現を使用していない

### 品質

- [ ] 誤字脱字がない
- [ ] 半角全角が統一されている
- [ ] デザインの一貫性が保たれている
- [ ] 聴衆の最後列からも読める文字サイズである
